# 양자 공부 노트

Quarto로 작성하고 GitHub Pages로 공개하는 개인 공부 블로그입니다.

## 미리보기

Quarto를 설치한 뒤 이 폴더에서 `quarto preview`를 실행합니다.

## 새 글 쓰기

1. `posts` 아래 새 폴더를 만듭니다.
2. `posts/first-note/index.qmd`를 복사합니다.
3. 제목, 날짜, 본문을 고칩니다.
4. 공개할 준비가 되면 `draft: true`를 삭제합니다.
5. GitHub에 변경을 올리면 자동으로 발행됩니다.

그림은 글 폴더에 함께 저장하고 `![그림 설명](파일명.svg)` 형식으로 넣습니다. PNG와 JPG도 사용할 수 있습니다.

`posts/first-note`는 공개되지 않는 작성 예시입니다.
